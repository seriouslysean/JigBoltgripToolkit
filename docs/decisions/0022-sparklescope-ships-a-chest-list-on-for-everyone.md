# 0022. Sparklescope ships a chest list on for everyone

- Date: 2026-11-27
- Status: accepted
- Scope: Sparklescope 6000
- Kind: data

## Context

No in-game signal tells a chest before it is opened.

## Decision

`Data/Chests.lua` holds 642 object IDs of lootable world objects that are not herbs or ore, generated by `tools/chests.py` from cmangos classic-db (GPL-3.0) and Forever's `Lock` table. It counts for every player. Learn Chests From (Self Found, Friends) covers only what the list lacks: chests Forever added.

## Reasons

- The cursor, tooltips, vignettes, the Opening spell's range, the loot and world-loot checks, objects coming into range and the object's model all came back empty; a second sweep read the same for a chest, a chair, a mailbox and a quest crate (Sparklescope6000 `docs/design.md`, "Chests").

## Rejected

- The list as a Public stop of Learn Chests From (`53ec295`).
- Guessing from English name words (precision 0.90, recall 0.30).
- Guessing from IDs near a known chest (precision 0.73).
- Model shapes: unreadable in game.

## Versions

- Sparklescope6000 `00d70b0`
- client 1.60.1 (71139)

## Tests

- Specs: "loot from the picked chest teaches it" and the other "chest learning" cases (`tests/learn_spec.lua`).
- Deck: the Battered Chest had fireflies, 2026-11-27.

## Reopen if

A game build adds chests in bulk, or a client update exposes an object's type, lock or model.
