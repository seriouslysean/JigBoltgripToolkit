# 0062. Fishing levels come from Fishing Sources cards, one setting like Recipe Vacuum

- Date: 2026-11-25
- Status: accepted
- Scope: Tackletron
- Kind: options pages

## Context

The community's table, what the player sees, and later other players' reports are three sources of a zone's level.

## Decision

One setting, the Fishing Sources cards from the toolkit (`lib.SOURCE_LEVEL`, `lib:SourceCards`), shared with Recipe Vacuum's Recipe Sources. Self Found tracks only what the player sees. The next card adds the community's table (`Data/FishingLevels.lua`, generated by `tools/fishing_levels.py`), always marked as expected and replaced by what is seen. The default is Self Found, 2026-11-26. The card text is worded as Recipe Vacuum's, "Tracks only ...", "Also tracks ...". The options page is built by the toolkit from a table in the toolkit's order, sources first. Replaced in part by 0063 once that is built.

## Reasons

- Same cards, same wording and same order as Recipe Vacuum (`ns.levelText`).
- The page order is 0040.
- Self Found and Friends is the default; Public stays for players who gather data.

## Rejected

- A card for Friends before sharing exists.

## Versions

- Tackletron `5b6945d`, `086219b`, `58bdf76`, `0b07888`, `3b172df`, `e1f2bf4`
- kit MINOR 24, 26, 43

## Tests

- Specs "by default only what the player sees counts: nothing seen, nothing expected", "Dustwallow with nothing seen: community data expects fishing from 126, no escapes from 225", "Self Found, refused at this skill: the fishing button is dimmed".
